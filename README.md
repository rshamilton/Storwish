# Storwish
A python program that splits a files into a bunch of binary files, one per folder in the directory given.
----

## Usage
 - Run main.py (python main.py)
- Choose a mode. You can't reconstruct files if you havn't split one yet!
    
If splitting:
- Enter the path to the intended file to split in standard format: ~/Documents/ExampleFolder/Image.anything
- Enter the path to the folder containing subdirectories to split the file into: ~/Documents/ExampleFolder

If reconstructing:
- Enter the path to the to where you want the reconstructed file to land: ~/Documents/ExampleFolder
- Enter the path to the folder containing subdirectories to split the file into: ~/Documents/ExampleFolder
- Choose if you want to delete the old chunks
